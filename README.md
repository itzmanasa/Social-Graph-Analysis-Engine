# Social Graph Analysis Engine

A graph-based social networking engine built in C that models users as nodes and friendships as undirected edges.
The project demonstrates core Data Structures and Algorithms concepts through features such as friendship mapping, mutual friend detection, and friend recommendation systems.

---

## Features

* Add new users
* Create friendships between users
* View friends list
* Find mutual friends
* Suggest friends using Friends-of-Friends logic
* Console-based interactive menu system

---

## DSA Concepts Used

* Graphs
* Adjacency List Representation
* Graph Traversal
* Searching
* Relationship Mapping

---

## Technologies Used

* C Programming Language
* Standard C Libraries
